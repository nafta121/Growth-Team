# Product Requirements Document (PRD)

## Tujuan Aplikasi (OutboundPro)
Aplikasi manajemen untuk tim Fasilitator Outbound Madiun untuk membantu menangani event outbound dan training. Tujuannya mempermudah fasilitator melihat event, memantau rundown secara aktual, dan komunikasi real-time antar tim.

## Target Pengguna
- **Fasilitator Lapangan:** Mengakses web app via Handphone di lapangan terbuka. UI HARUS memprioritaskan tampilan mobile (Mobile-First Design), tombol mudah diklik, dan teks mudah dibaca di bawah sinar matahari.
- **Lead/Admin:** Memasukkan jadwal acara dan menyusun urutan sesi.

## Kebutuhan Non-Fungsional Utama
- **Performa:** Loading < 3 detik di jaringan seluler.
- **Real-time:** Pesan chat dan pembaruan status rundown ("Sesi Berjalan") harus aktual dan cepat.
